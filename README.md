# النجاة — رحلة سوداني بين حربين

لعبة قصصية تفاعلية (Interactive Fiction) بالعربية والإنجليزية، تتبع طفلًا سودانيًا من دارفور عبر ثلاث حقب: نزاع دارفور، ثورة ديسمبر، وحرب ٢٠٢٣ — ثم مسارات النجاة والعبور.

> **ملاحظة محتوى:** اللعبة مستوحاة من أحداث حقيقية لكنها عمل خيالي. كل الشخصيات خيالية. تتضمن مشاهد عن الحرب والنزوح والجوع والموت — قد لا تناسب الأطفال الصغار.

---

## 🎮 نظرة سريعة

| البند | القيمة |
|---|---|
| **اللغة** | العربية (افتراضي) والإنجليزية، بتبديل فوري |
| **المشاهد** | ٩٨ مشهدًا (٥٥ أساسي + ٣٤ عقدة إضافية + ٩ حلقات تكرارية) |
| **النهايات** | ٩ نهايات مختلفة (سلام، عبور، تضحية، دفتر، شاهد، غرفة طوارئ، رماد القلب، حرب لا تنتهي، سقوط على الطريق) |
| **الرفاق** | ٩ شخصيات مصاحبة بتعزيزات فعّالة |
| **التقنيات** | HTML + CSS + JavaScript خالص، بدون أي مكتبات خارجية |
| **الحجم** | ملف واحد `index.html` (~١٢٠ كيلوبايت) — يعمل بلا إنترنت |
| **PWA** | قابل للتثبيت على Android وiOS 16.4+ |

## ✨ المزايا

### سرد وقرارات
- **٩٨ مشهدًا** بشجرة سرد متشعّبة
- **حلقات تكرارية (Loops):** مشاهد تتكرر لعدة ليالٍ حتى تصل إلى نتيجة
- **قرارات مخاطرة:** بعض الخيارات قد تنتهي بالموت (قابلة للتراجع بزر ↩️)
- **رفاق:** شخصيات تنضم إليك وتقدّم تعزيزات في مشاهد محددة
- **إنجازات يومية** تُسجَّل في «المذكرات»

### واجهة المستخدم
- **مظهر ليلي/نهاري** تلقائي حسب إعدادات النظام
- **دعم كامل للعربية (RTL)** والإنجليزية (LTR) بتبديل زر واحد
- **تصميم متجاوب** من ٣٢٠ بكسل حتى ١٠٢٤ بكسل
- **دعم Safe Area** لهواتف iPhone ذات الحافة
- **رسوم SVG** أصلية لكل مشهد (١٥ خلفية مختلفة)

### الصوت
- **موسيقى خلفية مولَّدة** بـ Web Audio API — لا ملفات صوت خارجية
- **مزاج صوتي متغير** حسب المشهد (حرب، ليل، سجن، سوق...)
- **زر كتم/تشغيل** دائم في الزاوية

### حفظ وتحميل
- **حفظ تلقائي** عند كل قرار
- **٣ خانات حفظ يدوية**
- **تراجع (Undo)** خطوة واحدة في أي لحظة، حتى بعد الموت
- **مزامنة اللغة** مع التخزين المحلي

## 🧩 طبقات التجربة والإضافات

المشروع يحافظ على محرك القصة وبيانات المشاهد والقرارات في `index.html`، ويحمّل التحسينات من ملفات مستقلة بعد اكتمال تعريفات اللعبة:

- `alnajat-v2.js`: أدوات الوصول، تكبير النص، التباين، تقليل الحركة، والقراءة الصوتية.
- `alnajat-cinema.js`: انتقالات سردية وخريطة فصول الحكاية.
- `alnajat-world.js`: خريطة جغرافية سردية لمحطات السودان، مع تمييز المدن التي وصل إليها اللاعب.
- `alnajat-characters.js`: أطلس تفاعلي للرفاق والشخصيات التي التقاها اللاعب، يستند إلى بيانات الشخصيات الموجودة دون اختراع أحداث جديدة.
- `manifest.json` و`sw.js`: تعريف التطبيق القابل للتثبيت والتخزين المؤقت للملفات الأساسية وطبقات التجربة.


### دفتر الذكريات — Memory Book

- `alnajat-memory-book.js`: يتيح للاعب حفظ مقاطع من المشاهد التي يختارها، وإضافة تأملات شخصية، والبحث داخل الذكريات ونسخها أو حذفها.
- يمكن تصدير دفتر الذكريات بصيغة Markdown للاحتفاظ به خارج اللعبة.
- تُخزّن الملاحظات محلياً في المتصفح، ولا تُرسل إلى خادم. هذه الميزة مستقلة ولا تغيّر نص القصة أو نتائج القرارات.
- حد الدفتر ٢٠٠ لحظة محفوظة لتفادي استهلاك مساحة التخزين بلا حدود.

### ملاحظات تشغيل مهمة

- الخريطة الجغرافية تستخدم Leaflet وخرائط OpenStreetMap؛ لذلك تحتاج اتصالًا بالإنترنت لتحميل مكتبة الخريطة وطبقاتها. بقية اللعبة تظل قابلة للعمل دون اتصال بعد تحميل ملفاتها وتخزينها.
- الخريطة سردية وليست أداة ملاحة أو مصدرًا للمعلومات الميدانية أو تقييم السلامة.
- طبقات الإضافات تحسينات مستقلة، ولا تستبدل مشاهد القصة أو خياراتها أو نهاياتها.
- بعد نشر تحديث جديد، قد يحتاج التطبيق المثبّت إلى فتحه مرة واحدة مع الاتصال بالإنترنت حتى يتلقى Service Worker الجديد.

### فحص ما قبل الإصدار

1. فتح اللعبة بالعربية ثم الإنجليزية.
2. بدء رحلة جديدة ومتابعة حفظ سابق.
3. التأكد من عمل المذكرات والسوق والأحداث والتراجع وخانات الحفظ.
4. فتح أدوات الوصول وخريطة الفصول والخريطة الجغرافية.
5. تجربة إغلاق النوافذ بزر Escape وعلى شاشة الهاتف.
6. التأكد من بقاء التقدم بعد إعادة تحميل الصفحة.
7. اختبار وضع عدم الاتصال بعد تحميل الملفات أول مرة.

> لم تُعتبر هذه القائمة اختبارًا بصريًا مكتملًا للمتصفح؛ يجب تنفيذها على الموقع المنشور وعلى هاتف فعلي قبل إعلان الإصدار مستقرًا.

## ✦ Director's Cut — طبقة المخرج

أضيفت طبقة مستقلة لإثراء التجربة من دون تعديل محرك القصة أو قراراتها:

- `alnajat-director.js`: غرفة المخرج، سجل القرارات المتتابع، أرشيف النهايات، تقرير الرحلة، النسخ الاحتياطي والاستعادة، وإرشادات تثبيت التطبيق.
- يسجل أثر القرارات الجديدة منذ تفعيل الطبقة؛ لا يدّعي إعادة بناء اختيارات سابقة لم تكن محفوظة.
- يمكن تصدير بيانات التقدم بصيغة JSON واستعادتها على الجهاز نفسه أو جهاز آخر.
- يظهر مؤشر اتصال/انقطاع، مع استمرار اللعب اعتمادًا على الملفات المخزنة محليًا بعد تحميلها.
- يضيف زرًا للوصول إلى أدوات الرحلة من القائمة والشريط العلوي.

### حدود مهمة

- سجل القرارات الجديد منفصل عن محرك اللعب ولا يغيّر آثار الاختيارات أو شروط النهايات.
- النسخ الاحتياطية تحتوي بيانات تقدم محلية؛ تعامل معها كبيانات شخصية ولا تشاركها علنًا.
- استعادة نسخة احتياطية تستبدل مفاتيح اللعبة المطابقة على المتصفح الحالي، ويُنصح بتصدير نسخة حديثة قبل الاستعادة.
- التثبيت والعمل دون اتصال يعتمدان على دعم المتصفح ونجاح تحميل ملفات التطبيق أول مرة.
